## 🚀 Overview

NFTWall Reward Claimer is a lightweight, client-side web tool that allows NFTWall users to claim their OZONE rewards directly from their smart contract without needing to access the main dashboard.

**Live Demo:** [https://nftwall-claimer.vercel.app](https://nftwall-claimer.vercel.app) *(replace with your actual URL)*

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🔌 **One-Click Connect** | Connect MetaMask or any EVM wallet instantly |
| 📊 **Auto Reward Detection** | Fetches your `myBusiness` value from NFTWall API |
| ⚡ **Smart Claim Amount** | Calculates optimal claim size based on available rewards |
| 🔐 **Secure & Local** | All transactions are signed by YOUR wallet — no private keys leave your device |
| 🧾 **Transaction Preview** | See exactly what will be sent before approving |
| 📱 **Mobile Friendly** | Fully responsive design that works on any device |

---

## 🛠️ How It Works

1. **Connect Wallet** — Connect your EVM wallet (MetaMask, Trust Wallet, etc.) to Ozone Chain
2. **Auto-Fetch Rewards** — The tool calls NFTWall API to get your `myBusiness` value
3. **Preview Transaction** — Review the claim amount and contract interaction
4. **Claim** — Approve the transaction in your wallet
5. **Receive OZONE** — Tokens are sent directly to your wallet
